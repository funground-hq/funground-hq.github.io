# About

funground is creative coding for learners: a small Python library for drawing, animation and sound.
It is made by Samir Joshi. AI assistants (Anthropic's Claude) wrote much of the code and the text, and
the maintainer set the goals and reviewed the work. How the AI was used is written down in
[AI-USAGE.md](https://github.com/funground-hq/funground/blob/main/AI-USAGE.md).
