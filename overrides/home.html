Three things you can do today

Each one is a short chapter in the guide.

Draw

Shapes, colour, text and paths. Every picture is a few lines you can read.

f.fill("gold")f.square(80, 80, 160)f.fill("hotpink")f.circle(400, 200, 140)

Animate

A draw() function runs sixty times a second. Change a number each time and things move.

def draw():    f.background("oldlace")    f.translate(320, 200)    f.rotate(f.frame_count * 2)    f.square(-60, -60, 120)

Make sound

Tunes from text, a tabla theka, and thirteen Hindustani ragas with their aroha and pakad built in.

yaman = f.raga("Yaman")f.melody(yaman.aroha, sa="D4").play()f.tala("Teentaal", tempo=100).loop()

Teaching a class?

Everything runs in the browser, so a lesson needs no installs. The guide ends with eight projects and a Studios chapter for running a group session.

  • Projects with a brief, steps and a finished example: rangoli, event posters, a voice-controlled game.
  • Examples are original and CC0. Use them in your materials freely.
  • Share a sketch as a link. Nothing is stored on a server.

Works where you are

BrowserWindowsMacLinuxgithub.dev

When you want funground on your own computer, with your own editor and files, install it with pip. You need Python 3.11 or newer.

python -m pip install funground

funground 0.1 is an alpha: a few parts are still being tested. Chapter 1 shows the steps one by one.
