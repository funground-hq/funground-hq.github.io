Where funground comes from

Processing and p5.js

The sketch: setup() once, draw() sixty times a second. p5.js runs in any browser.

Kept
The sketch, and the browser.
Changed
You write Python, not JavaScript or Java.

DrawBot

The script: a Python file that makes a poster or a PDF with real text. It runs on a Mac only.

Kept
Scripts, PDF and SVG with real text.
Changed
Windows, Mac, Linux and the browser.

How it is built

Cairo draws, pygame-ce opens the window, Pyodide runs it in the browser. Free software under the LGPL-2.1; the examples are CC0.
